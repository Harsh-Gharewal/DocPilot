Deployment Runbook

This runbook outlines standard deployment procedures for core backend services across production Kubernetes clusters.

Healthcheck Endpoints

Every microservice must expose a /health endpoint returning HTTP 200 with status ok. If the vector store or database becomes unreachable, /health responds with HTTP 503 and logs CRIT_HEALTHCHECK_FAILED.

Rolling Updates

Kubernetes deployments use a rolling update strategy with maxSurge set to 25% and maxUnavailable set to 0. This guarantees zero-downtime service deployments.
